# Deutsch A2.2

تطبيق تعليمي خفيف لتعلّم الألمانية من مستوى A2.2، مع شرح عربي اختياري.

**النسخة المنشورة:** https://attiazaghloul.github.io/deutsch-a2-learning/

## المحتوى

- فصول `Netzwerk neu A2.2` من 7 إلى 12
- 306 كلمات مع شرح ألماني وأمثلة وترجمة عربية
- قاموس موحّد قابل للبحث بالعربي والألماني وفلترة حسب الفصل
- 12 نص قراءة مرتبطًا بموضوعات الكتاب مع مفردات وأسئلة فهم
- بطاقات مراجعة تفاعلية
- جمل جاهزة للمحادثة و36 تعبيرًا ومثلًا مناسبًا لمستوى A2
- 8 دروس قواعد تضم 24 موضوعًا و8 صور تعليمية أصلية
- 6 صور تعليمية أصلية لفصول الكتاب من 7 إلى 12
- 96 تمرين قواعد تفاعلي متنوع: إكمال، ترتيب كلمات، تصحيح أخطاء وتحويل جمل
- 244 سؤالًا وتمرينًا مع تصحيح فوري وحفظ للتقدم
- قراءة صوتية للنصوص والكلمات والأسئلة والتعبيرات بالألمانية والعربية
- تصميم هادئ بخطي Cairo للعربية وCarlito/Calibri للألمانية

## التشغيل محليًا

لا يحتاج التطبيق إلى تثبيت حزم:

```powershell
python -m http.server 8742 --directory app
```

ثم افتح `http://localhost:8742`.

## النشر

يُنشر محتوى مجلد `app` تلقائيًا على GitHub Pages عند الدفع إلى فرع `main`.
